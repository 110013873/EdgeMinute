# --- Jetson aarch64 JIT 崩溃修复：钉死 numba / llvmlite ---
# Jetson AGX Orin / JetPack 5.1.2 / Python 3.8 上，更高版本 llvmlite 的 JIT 内存
# 链接器（LLVM RuntimeDyld）在长音频/大内存布局下会触发 aarch64 重定位偏移超 33 位的
# 断言 `isInt<33>(Result)`，直接 core dump（Aborted）。实测 numba 0.56.4 + llvmlite
# 0.39.1 这套旧组合在本设备上不触发该断言，稳定可用。
# 正因钉死此组合，app.py 才无需再设 NUMBA_DISABLE_JIT=1（该开关会拖慢 CAM++）。
# 升级前务必在 Jetson 实测，否则崩溃/变慢会回归。

llvmlite==0.39.1
